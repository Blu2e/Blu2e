OWASP Juice Shop Security Assessment

1. Project Overview
 - Project : OWASP Juice Shop Security Assessment
 - Purpose : 웹 애플리케이션의 보안 구조를 이해하고 취약점을 분석하는 실습
 - Target : OWASP Juice Shop
 - Status : In Progress

2. Lab Environment
 - Component / Environment
 - Attacker / Kali Linux
 - Target / Ubuntu
 - Target Application / OWASP Juice Shop
 - Proxy Tool / Burp Suite Community Edition
 - Network / VirtualBox NAT Network

3. Project Objectives
 - HTTP Request / Response 분석
 - 웹 애플리케이션의 인증 구조 이해
 - 서비스 및 공격 표면 분석
 - 취약점 식별 및 안전한 검증
 - 보안 개선 및 재검증

4. Assessment Process
 1) Lab Environment Setup
 2) Reconnaissance
 3) HTTP Traffic Analysis
 4) Vulnerability Analysis
 5) Security Verification
 6) Remediation
 7) Final Report

5. Findings
 - 현재까지 확인된 취약점 없음.
 - 보안 분석 진행 중이며, 검증된 결과를 추후 기록할 예정

6. Evidence
 - 실습 과정에서 수집한 화면 캡처 및 분석 자료 정리

7. Final Report
 - 프로젝트 종료 후 분석 결과와 개선 사항 정리 예정

실습 범위: 개인 가상 환경에서 구축한 테스트 시스템
